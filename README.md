# Vijay Bommireddy — personal website

Public portfolio: https://Vijay-glitch495.github.io/

A buildless, responsive GitHub Pages website introducing Vijay's full-time business intelligence work and independent research.

## Files

- `index.html`: biography, experience, publications, projects, service, and contact details.
- `styles.css`: responsive presentation, keyboard focus styles, reduced-motion and print support.
- `script.js`: mobile navigation, publication filters, and BibTeX copy with a manual-copy fallback.
- `assets/`: portrait, project results figure, and favicon.
- `.nojekyll`: serve the static files directly.

No build tool, dependencies, API keys, cookies, tracking, or account access is needed. Publish the `main` branch from the repository root in GitHub Pages settings.

## Content maintenance

Edit the relevant section in `index.html`. When adding publications, update the filter counts and add the corresponding BibTeX entry in `script.js`. Distinguish published conference papers, accepted work, and preprints. Specify the exact track for academic service.
